Phase II / The Multiverse

Four models. One Range.

Your Range is built from the convergence of four independent, probabilistic Monte Carlo engines—each approaching uncertainty differently. This engine produces an output fundamentally more credible than any single model.

Model I / Parametric

Generates 10,000 return sequences from a log-normal distribution calibrated precisely to your asset allocation.

Model II / Empirical

Randomly draws actual annual return sequences from 1926–2025, preserving extreme market outcomes.

Model III / Valuation

Uses the current Shiller CAPE ratio to dynamically shift expected returns based on current valuations.

Model IV / Regime

Samples multi-year blocks from historical economic regimes structurally similar to current conditions.
